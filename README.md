LocalDrive is your own personal Google Drive that lives on your computer. No subscriptions, no third-party servers, no limits. Everything you store stays on hardware you control. Whether you're saving family photos, sharing work documents with colleagues, or creating a backup of important files, LocalDrive gives you the power of the cloud without giving away your privacy.

Imagine having all the convenience of Google Drive—accessing files from any device, sharing links with friends, organizing photos—but knowing that every byte of data is stored securely on your own machine. That's LocalDrive.

## 📂 What Can You Do with LocalDrive?

### 📁 File Management Made Easy

Upload and organize files in any folder structure you like. Create folders, rename items, move files between directories, and search for specific documents. The interface is clean and intuitive, designed for everyday users who don't want to learn complicated commands.

### 🔄 Version History

Made a mistake? No problem. LocalDrive keeps track of previous versions of your files. If you accidentally overwrite an important document, you can roll back to an earlier version with just a few clicks. It's like having a time machine for your files.

### 🗑️ Trash and Recovery

Deleted something by accident? All removed files go to a trash folder where they stay for a configurable period. You can restore them at any time before they're permanently erased. It gives you peace of mind when cleaning up old files.

### 🔗 Link Sharing

Want to share a large video with a friend or send a document to a colleague? Right-click any file or folder and create a shareable link. You control whether the link is public or password-protected, and you can set expiration dates to keep things secure.

### 🖼️ Photo Gallery

## ⚙️ Technical Details for the Curious

While you don't need to be a programmer to use LocalDrive, here's what makes it tick:

- **Server**: A single Go binary that runs on any major operating system
- **Apps**: Built with Flutter for a consistent, smooth experience on all platforms
- **Database**: SQLite for reliable, file-based data storage
- **Docker**: Easy deployment for NAS devices and home servers

This stack means LocalDrive is incredibly fast, consumes minimal resources, and works on virtually any hardware—including an old laptop you might have sitting in a drawer.
